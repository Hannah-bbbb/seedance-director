# 条件规则

以下为官方指南的精简转述及本项目的适配建议；不是完整能力清单。按当前任务读取相应部分。

## 人物与素材绑定

- 用少量稳定特征定义人物，后文始终使用同一称呼；说明每张素材约束哪些内容，避免将场景或服装参考误用为脸部参考。
- 若强调人脸一致性，优先准备单独的清晰脸部图和单人全身图。人物设定拼图、多视图用于设计审阅很方便，但直接送入视频模型可能造成重复人物或身份混淆；先建议拆成独立素材，不自动替用户裁剪或重新生成。
- 引用以“图片N / 视频N / 音频N”关联真实输入。多个角度确实属于同一主体时说明关联；不要把每个角度定义为不同人物。
- 只保留有明确职责的素材，不为凑齐“人物＋场景＋运镜＋音乐”而要求额外文件。

## 编辑与续写

- 参考任务：说明从素材借用哪种特征，而不是整段照搬。
- 编辑任务：直接点名目标视频、修改对象和保留项；不要仅写“参考视频1”，以免意图变成另拍一段。
- 续写任务：明确生成原片之前还是之后的内容，以及衔接动作、人物和环境。不要承诺新输出包含完整原片，也不要保证无缝衔接。
- 原创示例，仅用于展示意图差异：
  - 参考：借用视频1的侧向跟拍方式，拍摄一名信使穿过雨后庭院。
  - 编辑：修改视频1，把信使手中的纸伞换成蓝色布伞，人物、行进动作和机位保持原样。
  - 续写：生成视频1结束之后的内容。信使停在廊下收伞，抬头望向门口，延续原片的光线与衣着。

## 对白、声音与文字

- 用户要声音时区分台词、音乐与音效；不要因模型支持音频就擅自加旁白或配乐。原台词逐字保留，需要换语言或改读音时另行说明。
- 官方提供的可选表达记号：音乐用圆括号，音效用尖括号，台词用花括号，字幕用方头括号。它们帮助分隔文本，不是所有宿主通用的参数或强制协议。
- 说话者、语言和语气要明确。用户要求多语言对话时保留其要求并分角色标注，不机械强制为单一语言。
- 屏幕文字写清准确内容、位置、出现方式与时机；“无字幕”“无文字”只在符合用户意图时使用。不保证靠约束词消除所有意外字幕。

## 反馈驱动的修订

| 用户反馈 | 优先检查与下一步 |
| --- | --- |
| 换脸、出现重复人物 | 检查主体定义与多视图输入；建议独立脸部图，减少歧义。 |
| 动作混乱或不连贯 | 缩减同一镜头同时发生的事件，补前后动作承接；保留必要的动作戏。 |
| 风格漂移 | 检查输入素材与目标风格是否冲突，明确全片风格；不擅自改素材。 |
| 画面发糊 | 先核对源文件分辨率、脸部占比、预览缩放与压缩；堆砌“高清”不是修复证据。 |
| 续写衔接跳变或劣化 | 检查原片边界与续写次数，给出剪辑或重新规划建议；不自动重跑或承诺修复。 |
