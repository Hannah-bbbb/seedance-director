# Seedance Director

一个面向 Seedance 2.0 的轻量提示词 Skill。当前为 **v0.1.0**，处于反复评审阶段，尚未安装到 Codex。

## 内容

- [SKILL.md](SKILL.md)：提示词编写、检查和局部迭代的入口。
- [条件规则](references/conditional-rules.md)：人物素材、编辑续写、音画表达与故障反馈。
- [评审用例](evals/cases.md)：无需调用视频生成的人工回归清单。
- [版本记录](CHANGELOG.md)：每轮调整的目的与验证范围。

本项目依据[火山引擎官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=zh)独立整理，不代表官方发布或效果保证；不附带视频、图片或账号材料。

## 迭代方法

1. 使用具体创作请求评审提示词，记录哪里偏离意图；无需先安装 Skill 或提交生成。
2. 只修改支撑该问题的规则或例子，并回看相关用例。新问题值得持续回归时再增加用例。
3. 更新 SKILL.md 的 metadata.version 和 CHANGELOG.md，提交后打同名版本标签。

采用 `v主版本.次版本.修订号`：措辞与勘误用修订号；新增兼容工作方式用次版本；破坏已有约定的调整用主版本。正式修改前先阅读 Git 历史与现有内容，保留用户已接受的选择。

仓库目前不提供自动安装脚本、自动发布动作、模型调用或积分消费能力。首次版本只做文档与结构核验，尚未验证实际视频生成质量。
