# 人工评审用例

这是后续迭代用的行为回归清单，不是已执行的模型效果测试。将 SKILL.md 与所需参考交给评审者，使用以下请求；只撰写提示词，不提交生成、上传或扣分。不按固定字句评分。

| 请求与输入事实 | 合格表现 |
| --- | --- |
| 没有素材：“写一段女子在古代庭院中抬手接雨的提示词。” | 不虚构图片编号；动作、环境与机位清楚；不强制三镜头、时间戳、配乐或旁白。 |
| 输入顺序为图片甲、视频甲、图片乙；甲是角色、乙是场景。要求参考视频运镜。 | 图片甲→图片1、图片乙→图片2、视频甲→视频1；明确三者用途，不按混合总序号写成图片3。 |
| 一张人物三视图：“脸别变，做成单人视频。” | 提醒多视图直接输入的身份歧义，建议独立脸部/全身素材；不声称三视图一定更稳，不自动裁图或生图。 |
| “把视频1中红灯笼改为青色，其他不变。” | 识别为编辑，明确目标、替换和保留项；不改成只借鉴风格的新视频。 |
| “向后续写视频1，人物放下杯子。” | 保留向后续写意图与动作衔接，不写成参考重拍；不承诺原片自动包含在输出里。 |
| “一镜到底，快速翻身越过矮墙，9:16，10秒，无配乐。” | 保留动作戏与单镜头要求；不擅自慢动作、不插切镜、不加音乐；将比例与总时长独立列为设置。 |
| “只把上一稿的酒红衣服改成墨绿，其他不变。” | 只调整服装色彩及必要指代，不重写镜头、人物身份和台词。 |
| “0–3秒进门，3–6秒说台词，必须精确。” | 保留明确时序意图，说明模型不保证逐秒命中；不伪称精确可控，不直接提交生成。 |
| “女生用中文，男生用英语回答，字幕必须是指定原句。” | 保留用户的多语言要求及原句，清楚绑定说话者；不追加禁字幕约束。 |
| “参考视频3”，但实际只提供一段视频。 | 指出编号缺口并请求澄清，不编造第三段视频，也不自行假定视频3就是视频1。 |

若评审失败，记录：输入事实、实际输出、偏离意图之处、建议改动、对应提交或版本。没有生成结果时，只能评价提示词行为，不能评价画面质量。
